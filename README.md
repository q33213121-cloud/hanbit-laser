# 한빛레이저 (Hanbit Laser)

> 작은 물건에 특별한 의미를 새기는 맞춤 레이저 공방

## 项目简介
这是 Hanbit Laser 的静态展示网页项目，使用 **HTML + CSS + 少量 JS** 构建。

## 部署方法
1. 在 Vercel 新建 **Static Site** 项目  
2. 上传整个 `hanbit-laser` 文件夹  
3. **Build Command** 留空  
4. **Output Directory** 设置为 `.`  
5. 发布即可访问网页

## 技术栈
- HTML5
- CSS3
- JavaScript
- Google Fonts (Noto Sans KR)
